# Non-goals

PRs that do these will be closed with a pointer here.

1. **A coding agent.** OpenClaw, OpenCode, Claude Code, Codex,
   Hermes exist.
2. **A skill marketplace / 200-skill pack.** ECC exists.
3. **Kernel or microVM isolation.** nono, E2B, NemoClaw exist.
4. **Embedding RAG / vector store.** Out of the product thesis.
5. **Graph visualization / `/graphify` clone.** Graphify exists.
   Consume radius; do not become a graph IDE.
6. **Token compression of arbitrary tool output.** headroom and
   context-mode exist.
7. **Caveman / ADHD output voice.** Unrelated to the deny path.
8. **“We block CVEs”** as README text, star bait, or conference talk.
9. **Phone-home telemetry** in v0/v1.
10. **Fleet orchestration as the v0 headline.** Worktrunk and Orca
    exist. Fleet is v3 and optional.
11. **Windows kernel sandbox.** We do not even do Unix kernel
    sandbox.
12. **LLM-as-judge as the deny oracle.**

If a change only makes the README more impressive, it is a non-goal.
